# 見積書 進捗管理ツール

見積書の作成、見積書一覧の自動作成、各見積案件の進捗管理（受注／失注）を行える社内向けツールです。見積書を作成すると自動でGoogleスプレッドシートに転記され、見積書一覧として蓄積されていきます。使い方は「見積書作成ツールとしてだけ使う」「見積書一覧の自動作成まで使う」「進捗管理まで使う」の3段階から自由に選べます。

利用者は営業担当・責任者を想定しています。受注・失注・受注確度は「一覧」の「注文待ち（受注/失注チェック）」タブからワンクリックで記録・更新でき、スプレッドシートを直接編集する必要はありません。

## 公開URL
https://onuma-spec.github.io/anken-kanri-mitsumori/

## 構成
- `index.html` — ツール本体（単一HTMLファイル）
- `gas_template.gs` — 集計先となるGoogle Apps Scriptのテンプレート（`index.html`内の「①見積書データの保存先を用意する」からもコピーできます）
- `sync_gas_code.js` — `gas_template.gs`の内容を`index.html`内の埋め込みコードへ同期するスクリプト（開発用。利用者が実行する必要はありません）

## 仕組み
1. `index.html`をブラウザで開き、見積書を作成するフォームに入力して送信
2. 内容が自動で各社自身のGoogleスプレッドシート（見積ヘッダー・見積明細タブ）に転記される。書類番号もこの時点で自動採番される
3. 送信直後に印刷用の見積書レイアウトが表示され、そのまま印刷・PDF保存できる
4. 案件の決着がついたら、`index.html`の「一覧・ダッシュボード」→「注文待ち（受注/失注チェック）」タブから該当の品目を検索して「受注を記録」または「失注を記録」を押す。受注確度はプルダウンで選び直すだけで即座に反映される（いずれもワンクリックで完了し、スプレッドシートを直接編集する必要はない）
5. 提出状況・決着状況・注文待ち状況は「概要」タブでいつでも確認できる

`index.html`はフロントエンドのみで、データは一切保持しません。バックエンド（GAS＋スプレッドシート）は利用する各社が自分のGoogleアカウント内に個別に構築するため、データは各社のGoogle上に閉じます。

## 初期セットアップ
`index.html`をブラウザで開くと表示される「①見積書データの保存先を用意する」「②接続を確認する」の手順に沿って進めてください。GASコードのコピー・貼り付け・デプロイまで、画面内の案内だけで完結します。

セットアップ後、スプレッドシートに自動生成される「設定」タブに自社名など（自社名のみ必須）を、「登録リスト」タブに部署名候補・担当者一覧を入力しておくと、見積書作成フォームで選択できるようになります。

## 主な機能
- 見積書作成・見積書一覧の自動作成・自動採番（`prefix-yyyymm-連番`）
- 印刷／PDF保存用レイアウト、過去の見積書を複製しての新規作成
- 進捗ステータス（注文待ち／受注／失注）の自動判定
- **注文待ち（受注/失注チェック）**：受注/失注をワンクリックで記録、受注確度（A/B/C）をプルダウンで即時更新。有効期限を超過している品目は行全体を強調表示
- **取り消し**：受注・失注の記録直後に画面下へ「元に戻す」通知が表示され、タップまたは次の記録操作まで残る。直前の1件だけをその場で取り消せる（それより前の記録を修正したい場合は、スプレッドシートの「見積明細」タブを直接編集する）
- ダッシュボード（提出状況の月次推移、決着状況・受注率、注文待ち状況（受注確度別の見積合計額）、全品目一覧）
- **差分表示**（🔍タブ）：任意のタイミングで現在の全品目をバックアップ保存し、過去のバックアップと比較して新規追加・ステータス変化・受注確度変化・削除された品目を確認できる。削除された品目は選択して復元も可能
  - バックアップは「バックアップ保持数上限」（設定タブ、既定3件）を超えると古いものから自動削除される
  - 自動削除される前に残しておきたいバックアップは、差分表示タブから個別にJSONファイルへエクスポートし、後で読み込んで比較対象に戻せる（読み込みはバックアップの再登録のみで、現在のデータには影響しない）
- 見積書の削除（正規の削除操作。削除ログに記録が残り、差分表示から復元できる）

## データについて
すべてのデータ（見積書の内容・進捗・バックアップ履歴など）は、利用者自身が作成したGoogleスプレッドシートに保存されます。本ツール（`index.html`）や開発者側には一切のデータが送信・保存されません。

## 注意事項
GAS Webアプリは認証なし（アクセスできるユーザー：全員）で公開されるため、ウェブアプリURLを知っていれば技術的知識のある第三者がデータを閲覧・変更できる可能性があります。社内の信頼できるメンバーの範囲でURLを共有してください。
